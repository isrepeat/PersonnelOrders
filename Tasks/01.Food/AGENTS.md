# Регулярная обработка рапортов по питанию

- Обрабатывать рапорты из `Sources/<дата запуска>`. Результат — таблица продовольствия/сухпайка и выписки по соответствующим шаблонам из `Documents/Templates/Extracts [food]`.
- Для запуска 2026.10.09 обрабатывать только пять фотографий WhatsApp. Оба исходных DOCX исключены пользователем, включая список КОСЬКА. Три фотографии КОРНЕНКА образуют один рапорт на 76 человек.
- Рапорты МОРОЗОВИЧА и МІЗЯКА относятся к шаблону снятия с котла и выдачи сухпайка `[НАШИ]`. Для другого рапорта шаблон определять по содержанию и принадлежности военнослужащих.
- Дату, номер и подписанта приказа сопоставлять по `tbOrders` в `Tools/Накази.xlsx`. Отсутствующие ПІБ, звание, дату приказа или номер входящего документа не придумывать; явно запрашивать необходимые сведения.
- Исходный рапорт выражает запрос, а не подтверждает издание приказа. До подтверждения приказа выписка является проектом.
- По рапортам на сухпай заполнять только `Сухпрод`; `Продовольче` оставлять пустым. Прекращение сухпайка считать первым днём без сухпайка, используя формулу `=[@Початок]+[@Тривалість]` и calculatedColumnFormula таблицы.
- Таблицы оформлять в тёмной теме; фон пустой области листа тоже тёмный. Не закреплять строки и столбцы.
- Форматы ячеек и ширины основных колонок B:J переносить непосредственно из таблицы листа Сухпрод в РУХ_last.xlsx. ПІБ не выделять вручную: розовый фон и красный шрифт применяются только правилом conditionalFormatting duplicateValues. Дополнительные колонки помещать после J.
- После переноса форматов явно сохранять тёмную чёрную шапку и полосатые строки #262626/#383838 с белым текстом: исходные стили РУХ в тёмном режиме Excel могут не содержать явной заливки. Установа оранжевая, прекращение голубое. Не превращать таблицу в белую.
- В выписках дату приказа брать по дате рапорта, остальные реквизиты — из строки tbOrders этой даты. Начало сухпайка не определяет дату приказа. Период писать словами: «з 12 по 14 жовтня 2026 року:»; на стыке месяцев «з 29 вересня по 01 жовтня 2026 року:». Основание: «рапорт <звание> <ФАМИЛИЯ> <инициалы> (вх. № <номер> від <дата>)». Инициалы сверять по полному ПІБ автора в ШПО; для внешнего автора использовать доступные данные рапорта, не выдумывать отчество. Строку о поновлении на котловое в выписку сухпайка не добавлять.
- Версионность применять только к таблице рапортов: `v<Version> Рапорти_продовольче_сухпрод_<дата>.xlsx`. Сохранять предыдущие версии, новую создавать со следующим свободным номером. Выписки не переименовывать по этому правилу.
- Додаткова інформація оставлять пустой. Підстава в ячейках начинается с маленькой буквы: «рапорт ...». Для текущего запуска использовать подтверждённые пользователем номера от 08.10.2026: КОРНЕНКО 1656/26791-в, МОРОЗОВИЧ 1656/26786-в, МІЗЯК 1656/26790-в.
- Колонку Наказ заполнять числовым номером из tbOrders по дате рапорта; не оставлять пустой, если номер есть в справочнике. В текущем запуске все три рапорта от 08.10.2026, поэтому для всех 99 записей и трёх выписок — №291, підполковник Олег ЧЕРКАШИН.
- Между фамилией автора рапорта и инициалами использовать неразрывной пробел U+00A0 в выписках и в основании таблицы.
- Если полного ПІБ автора нет в ШПО, не сокращать известное имя до инициалов: использовать «Имя ФАМИЛИЯ» в грамматическом падеже основания, например «рапорт майора Юрія КОРНЕНКА».
- Имя файла выписки НАШИ брать из имени шаблона: `{yyyy}-{mm}-{dd} {OrderNumber} (снять с котла и выдать сухпай [НАШИ] - {Raporter}) {Signatory}.docx`. Raporter — фамилия автора в именительном падеже прописными буквами, например МІЗЯК или МОРОЗОВИЧ.
- То же правило Raporter действует для ЧУЖИЕ: `{yyyy}-{mm}-{dd} {OrderNumber} (снять с котла и выдать сухпай [ЧУЖИЕ] - {Raporter}) {Signatory}.docx`, например КОРНЕНКО. Закрывающая скобка располагается после фамилии автора, перед Signatory.
- В Raport и в основании таблицы указывать должность автора из подписанного рапорта в родительном падеже перед званием и именем: «рапорт командира ... капітана ...». Не заменять её кодом посады из ШПО.
- Для наших рапортов не включать «військової частини А7383» в Raport и основание таблицы. Для чужих сохранять принадлежность к части.
- В списках военнослужащих выписок звание и полный ПІБ писать в родительном падеже: «солдата ШАРКА Євгенія Івановича». В таблице ПІБ остаётся в именительном падеже.
- При заполнении DOCX заменять только текст плейсхолдеров, включая разбитые между фрагментами: сохранять pPr, rPr, шрифты, отступы, интервалы, табуляцию, пустые абзацы и оформление подписей исходного шаблона. Не уменьшать шрифт и не удалять абзацы ради сокращения числа страниц. Список наследует оформление абзаца периода шаблона; перед основанием добавлять пустой абзац того же шаблона. Последний пункт списка заканчивать точкой, остальные — точкой с запятой; основание заканчивается «).», как в шаблоне.
- Числа и даты хранить типизированными, ІПН — текстом. Не сопоставлять человека только по фамилии. Сохранять основание и ссылку на конкретный исходный файл.
- Готовые результаты текущего запуска хранить только в `Results/<дата запуска>`, выписки — в подпапке `Extracts`. Вспомогательные материалы сохранять только в `Work/<дата запуска>`.
