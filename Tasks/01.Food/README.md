# 01.Food — питание по рапортам

Регулярная задача: таблица продовольствия и сухпайка и выписки по исходным рапортам.

- `Sources/YYYY.MM.DD/` — исходные материалы запуска.
- `Results/YYYY.MM.DD/` — актуальная таблица и выписки в `Extracts`.
- `Work/YYYY.MM.DD/` — промежуточные данные, превью и проверки.

Запуск 2026.10.09 обработан только по пяти фотографиям WhatsApp. Оба DOCX исключены пользователем. Три фотографии КОРНЕНКА образуют один рапорт А0565 на 76 человек; МОРОЗОВИЧ — 3 человека; МІЗЯК — 20. Всего 99 записей сухпайка, 221 комплект, 331,5 кг воды. Продовольче пуст: рапорты обработаны только как заявки на сухпай.

Актуальная таблица: `Results/2026.10.09/v2 Рапорти_продовольче_сухпрод_2026.10.09.xlsx`. Предыдущая таблица сохранена как v1; исходный файл без префикса остаётся открытым в Excel и относится к старой версии. Форматы ячеек B:J и ширины перенесены из копии открытого РУХ_last без изменения оригинала. Формула прекращения `=[@Початок]+[@Тривалість]`, ПІБ подсвечивается только условным правилом дубликатов. Дополнительные сведения начинаются с K. Пустая область листа тёмная, закреплений нет. В Extracts остаются три проекта с прежними именами.

Актуальный полосатый вариант таблицы — `Results/2026.10.09/v3 Рапорти_продовольче_сухпрод_2026.10.09.xlsx`; v1 и v2 сохранены как история. В Extracts находятся оформленные выписки: 09.10.2026 №292 для МОРОЗОВИЧА; 12.10.2026 №295 для МІЗЯКА и КОРНЕНКА. По обновлённому tbOrders оба приказа подписывает підполковник Олег ЧЕРКАШИН. Периоды записаны словами, основания содержат инициалы; строка о поновлении на котловое удалена. МОРОЗОВИЧ Ю.М. и МІЗЯК А.В. сверены с ШПО. КОРНЕНКО отсутствует в ШПО; по фото использован доступный инициал Ю. Старые проекты выписок отправлены в корзину. Сведения о приказе в таблице v3 сохранены как в v2: исправление этой версии касается полосатого оформления.
