# Сверка продовольственного обеспечения за сентябрь 2026

Скрипты задачи находятся здесь, входные копии приказов и справочник ФИО — в Inputs, промежуточные данные и итоговая книга — в Results. Python и Node используются из общего установленного runtime Codex; Microsoft Excel нужен для пересчёта формул и сохранения XLSM с VBA.

Порядок обновления: обновить Inputs/Orders актуальными приказами, выполнить september_collect.ps1, analyze.py Results/РУХ_last.xlsx, september_prepare.py, september_build.ps1, september_verify.py и september_preview.mjs. Команды Python выполняются с -X utf8.

Копии РУХ_last.xlsx и Продовольче.xlsm считываются с рабочего стола. Оригиналы не изменяются. Сухпай считается по персональным назначениям и датам непосредственно из приказов. Исправленный №257 учитывается на 5–7 сентября без подмены месяца.

В основной смарт-таблице первая строка каждой даты содержит исходные данные, следующая — пересчитанные. Ярко-красные ячейки показывают значения к замене, ярко-зелёные — новые значения. Тёмный и коричневый фон различают строки пары. Строки не закрепляются. Пары нельзя суммировать.
