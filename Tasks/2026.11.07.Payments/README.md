# Выплаты 300 000 грн за 2025–2026 годы

Результат: Results/Выплаты_300000_2025-2026.html — реестр с поиском по ФИО, статусами, дословными пунктами и ссылками на исходные приказы. Найдено 53 человека, 56 записей, 16 пунктов в 15 приказах А7383.

Results/Виплати_300000_2025-2026.xlsx — реестр Excel: лист «Виплати» содержит 56 записей с ФИО, датой, номером и пунктом приказа, статусом, суммой и текстом об отдельном человеке; лист «Тексти наказів» содержит дословные пункты по абзацам. Переходы из реестра ведут к полным пунктам. Первое появление каждой записи отмечено v1 в колонке «Додано у версії». Книга содержит собственные стили CoffeePayments и CoffeeText; фон пустой области также тёмный, с чёрными границами. Закрепления и разделения окна нет. Добавление и удаление строк проверено в Microsoft Excel на временной копии: стиль сохраняется.

Источники: Documents/Orders, папки 2025 и 2026 всех частей. Исходники не изменялись. Проверено 2092 DOCX, 89 DOCX внутри ZIP и один DOC через Microsoft Word. Служебный файл ~$ исключён. Текстовый файл в Погодження не является приказом.

Work/scan_payments.py — поиск; Work/build_report.py — сборка отчёта; Work/audit.json — данные и проверяемая привязка к абзацам. Скрипт сборки выдаёт патч: текстовые результаты применяются только через apply_patch.

Work/build_xlsx.mjs создаёт XLSX через artifact-tool; Work/finalize_xlsx.py добавляет в бинарный OOXML-контейнер собственные стили таблиц, стиль пустой области и настоящие внутренние гиперссылки, отсутствующие в публичном API библиотеки. Выполнять последовательно. PNG в Work служат для проверки оформления.

Записи «виплатити» и «отримав/отримала» различаются. Повторные упоминания КАМЕНЄВА, БІНА и РАЦ сопоставлены вручную по полным ФИО; исходные падежи сохранены. В пункте 17 приказа от 05.10.2026 №288 последующий ненумерованный блок об оздоровительных ИМЕНИННИКУ сохранён в цитате для полноты, но исключён из реестра выплат 300 000 грн. Не установлены даты фактических перечислений по распоряжениям «виплатити»; платёжных документов в рамках задачи не исследовали.
