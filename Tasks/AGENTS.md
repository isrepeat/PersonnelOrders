# Организация задач

- Разовые задачи именовать `YYYY.MM.DD.Name`: сначала дата, затем краткое название.
- Регулярные задачи именовать `NN.Name`: постоянный номер с ведущим нулём, например `01.Food`. Новую папку регулярной задачи на каждую дату не создавать.
- Внутри задачи использовать `Sources`, `Results`, `Work` и `README.md`.
- У регулярной задачи каждый запуск хранить в подпапке `YYYY.MM.DD` отдельно в `Sources`, `Results` и `Work`.
- `Sources` содержит исходные материалы; не изменять их содержание.
- `Results` содержит только актуальные готовые файлы. Превью, журналы, промежуточные JSON и скрипты проверки сохранять в `Work`. Общие повторно используемые скрипты и справочники держать в корневом `Tools`.
- Предыдущие версии сохранять только при необходимости, в `Work/YYYY.MM.DD/Versions`; не смешивать их с актуальными результатами. ZIP не создавать без запроса.
- В `README.md` кратко фиксировать назначение задачи, состав результатов и нерешённые вопросы. Не смешивать разные задачи или исходные приказы в одном запуске.

## Оформление создаваемых Excel-таблиц

- Эти правила применяются ко всем Excel-таблицам, создаваемым в `Tasks` и его подпапках, если пользователь явно не задал другое оформление.
- Не закреплять строки и столбцы: не добавлять freeze panes и разделение окна. Табличные данные оформлять как умную таблицу Excel с заголовками и кнопками фильтров.
- Визуальный образец — таблица отпусков «А4085 → А7383. Щорічна основна відпустка» со второго скриншота пользователя: тёмная тёплая серо-коричневая палитра, светлый основной текст, оранжево-золотые акценты в заголовке отчёта и столбце ФИО, приглушённая серо-коричневая заливка шапки, тонкие тёмные границы ячеек. Не использовать синюю шапку и бело-голубые полосы из предыдущей таблицы сведений ШПО.
- Использовать Arial 11 для данных и шапки; заголовок отчёта делать умеренно крупнее, полужирным. Заголовки столбцов — полужирные, по центру, с переносом при необходимости.
- Тёмный фон задавать для всего листа, включая пустые ячейки ниже и справа от таблицы, а не только для заполненного диапазона. Использовать стили по умолчанию для пустой области, не создавать миллионы пустых ячеек.
- Границы ячеек должны быть всегда видны: явно задавать все внешние и внутренние границы тонкой сплошной линией стандартного чёрного цвета (`#000000`), включая пустую область листа. Не заменять границы скрытой сеткой или близким к фону оттенком.
- Оставлять небольшой отступ сверху и слева; над таблицей размещать короткий заголовок и, если нужно, одну строку с итогами или контекстом. Примечания размещать справа от таблицы через пустой столбец.
- Делать строки компактными: подбирать высоту по содержимому, без больших пустых областей внутри строк. Длинный текст переносить и подбирать ширину столбцов так, чтобы всё содержимое было читаемо. ФИО и описания выравнивать влево, короткие значения — по центру, если это соответствует образцу.
