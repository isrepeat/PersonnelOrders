# Пересечения периодов в РУХ

Актуальный результат — `Results/РУХ — перевірка перетинів.xlsx`. На листе «Що виправити» указаны адреса, предлагаемые действия и реквизиты приказов. Лист «Рядки РУХ» показывает исходные периоды, их пары и основания из книги. Адреса соответствуют сохранённому `РУХ_last.xlsx` на рабочем столе от 13.11.2026.

Отобраны все 90 сохранённых предупреждений «Перетин періодів за ІПН», включая строки с дополнительными предупреждениями. Вместе со связанными строками проверены 122 строки по 53 ІПН. Вложенные и спорные периоды оставлены на сверку по указанным документам. В исходный РУХ правки не вносились.
