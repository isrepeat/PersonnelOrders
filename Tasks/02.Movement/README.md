Регулярная задача подготовки отдельных книг РУХ для сверки и ручного переноса. Исходную рабочую книгу автоматически не изменять.

- `Sources/YYYY.MM.DD` — приказ и снимок РУХ, использованный для проверки закрытий.
- `Work/YYYY.MM.DD` — скрипты конкретного запуска, первичная выборка и превью.
- `Results/YYYY.MM.DD` — готовая версия `РУХ_<номер>_v<версия>.xlsx`; предыдущую версию не перезаписывать.
- Инструменты обработки РУХ находятся в `Tools` этой задачи; правила извлечения — в `РУХ_схема_обработки_приказов.md` рядом с этим README. Общие справочники ШПО и приказов остаются в корневом `Tools`, поскольку используются также задачей Food.
