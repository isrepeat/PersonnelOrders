# Таблицы движения по строевым приказам

Регулярная задача подготовки отдельных книг РУХ для сверки и ручного переноса. Исходную рабочую книгу автоматически не изменять.

- `Sources/YYYY.MM.DD` — приказ и снимок РУХ, использованный для проверки закрытий.
- `Work/YYYY.MM.DD` — скрипты конкретного запуска, первичная выборка и превью.
- `Results/YYYY.MM.DD` — готовая версия `РУХ_<номер>_v<версия>.xlsx`; предыдущую версию не перезаписывать.
- Инструменты обработки РУХ находятся в `Tools` этой задачи; правила извлечения — в `РУХ_схема_обработки_приказов.md` рядом с этим README. Общие справочники ШПО и приказов остаются в корневом `Tools`, поскольку используются также задачей Food.

Запуск `2026.10.05`: приказ №288. Результат содержит 4 строки на «Список», 31 на «Відсутні», 50 на «Прибули» и обзор 63 записей сухпайка. Часть событий уже внесена в целевую книгу: перед переносом обязательно проверить совпадения. На «Огляд» вынесены расхождения дат закрытия СЗЧ, отсутствие записи НАГОРНОГО в ШПО, групповые удостоверения без персонального соответствия и противоречие по КОНДРАТЮКУ.

Сборка из корня репозитория: запустить `Tasks/02.Movement/Work/2026.10.05/build_288.mjs` предоставленным средой Node.js, передав путь к `prepare_288.py`, новой версии XLSX и папке превью. Перед сборкой выполнить универсальное извлечение `Tasks/02.Movement/Tools/extract_order.py`; без `--output` первичная выборка сохраняется в `Work/<дата приказа>/events_<номер>.csv` этой задачи. Скрипт подготовки читает сохранённый снимок РУХ и актуальный ШПО только для чтения.
