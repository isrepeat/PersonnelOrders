# Звірка списків позбавлення та зменшення премії

На аркуші «ОС» вилучено записи осіб, виключених зі списків станом на 01.11.2026 включно. Джерело статусу — «Список» у настільному `РУХ_last.xlsx`. Зіставлення виконано за ІПН з урахуванням дат зарахування і виключення.

- `Results/Позбавлення.xlsx` — вилучено 1 рядок, залишилося 83. Звіт — `Results/Позбавлення.diff.html`.
- `Results/Зменшення.xlsx` — вилучено 2 рядки, залишилося 22. Звіт — `Results/Зменшення.diff.html`.

TableDiff підтвердив лише вилучення рядків. У НАУМОВА Олександра Ігоровича ІПН не зіставився. У «Списку» за повним ПІБ знайдено запис без дати виключення, рядок залишено.

На аркуші «Новоприбулі» в `Позбавлення.xlsx` заповнено пропуски для 12 осіб. Для перших двох записи зіставлено за ІПН та наявною датою фактичного прибуття на аркуші «Прибулі». Для решти взято ІПН, фактичне прибуття та номер наказу із жовтневих подій «Повернення до іншої частини» на аркуші «Відсутні». Звіт «Позбавлення» охоплює аркуші «ОС» і «Новоприбулі», звіт «Зменшення» — аркуш «ОС».
