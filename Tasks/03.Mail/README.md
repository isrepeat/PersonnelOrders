## Чтение и сопоставление

- Лист «Вч», таблица tbMilitary: ключ «В/ч», адрес «Місто / селише + район» и «Область». Номера нормализуются к украинской букве А и четырём цифрам; числовой и текстовый 7224 соответствуют А7224.
- Лист «Отправка», таблица tbMail: «Дата», «В/ч», «Номери, вказані на відправленнях». В сохранённом снимке запуска 2026.10.14 таблица ещё называется tbMilitary2; допускается только этот альтернативный вариант с обязательной проверкой трёх заголовков. Не искать данные в посторонних таблицах.
- Отобрать строки указанной даты, сгруппировать по части в порядке первого появления. Внутри части сохранить порядок строк. Делить на последовательные группы максимум по три документа. Остаток из одного или двух документов — отдельный конверт; не дополнять выдуманными номерами и не смешивать разные части.
- Номер из таблицы печатать как №1656/<номер> согласно образцу. Повторные номера автоматически не удалять: сохранять исходные строки для сверки. Не добавлять суффикс -в, дату или почтовый индекс без источника.
- Отправитель по предоставленному образцу — «Військова частина А7383», населённый пункт брать из tbMilitary. Получатель — «Командиру військової частини», затем «Військова частина Аxxxx» и адрес справочника. Область выводить только если заполнена. Существующие переносы адреса сохранять.
- При отсутствующем адресе, противоречивых дублях адреса, неоднозначном номере или превышении доступной высоты остановить сборку с конкретной ошибкой. Строки справочника с пустым ключом или служебным знаком + пропускать. Не искать адреса во внешних источниках и не исправлять названия населённых пунктов по предположению.

## Запуск и проверка

Использовать bundled Python и пакеты среды. Сначала сохранить снимок актуальной книги в Sources; незаписанные изменения открытого Excel в снимок не попадают. Не перезаписывать готовый результат: выбрать новое имя, прежнюю версию при необходимости переместить в Work/Versions.

```text
python Tasks/03.Mail/Work/build_envelopes.py --source "Tasks/03.Mail/Sources/2026.10.14/Військові частини.xlsx" --date 2026.10.14 --limit 3 --output "Tasks/03.Mail/Results/2026.10.14/Конверти_DL_тест_3.docx"
```

Для всех конвертов использовать --limit 0. Проверить выбранные номера и адреса по исходным строкам. Перед выдачей открыть все страницы рендера, проверить число страниц, отсутствие обрезания и сохранность шрифта. Если bundled LibreOffice отсутствует, экспортировать проверяемую копию через установленный Word в PDF в Work и растеризовать bundled Poppler. В Results оставлять только итоговый DOCX. Для печати с текущим Microsoft IPP Class Driver экспортировать PDF через «Файл → Экспорт → PDF/XPS», печатать DL, альбомная ориентация, фактический размер; не использовать Microsoft Print to PDF, который ранее менял формат на A4.
