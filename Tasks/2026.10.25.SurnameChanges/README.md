# Проверка смен фамилий в приказах за 2026 год

Сопоставлены ФИО по ИПН на листах ОС и АЛФ файла Tools/ШПО.xlsx; просмотрены тексты 311 DOCX из Documents/Orders/*/2026, включая исправленные копии. Основной набор А7383 содержит 301 файл за 01.01–20.10.2026. Источники не изменялись. Results/Смена_фамилий_2026.xlsx содержит две таблицы в кофейном стиле: шесть исправлений АЛФ и четыре остальные подтверждённые смены, с дословными цитатами и состоянием справочника. Work/analyze.py содержит проверку расхождений; Work/evidence.py извлекает цитаты; Work/build.mjs создаёт отчёт. Оба листа визуально проверены.

Подтверждено 10 смен фамилий: СОЛЯНИК → ВАСИЛЕНКО (25.02 №60 п.18), ГОРШКОВ → ГОРШКОВ-МУКОМЕЛА (02.03 №65 п.16), ШЕВЧУК → КИРИЧЕНКО (03.03 №66 п.9), РЄПІНА → ДЕДУХ (06.03 №69 п.14), ПОЛЯХ → ПОРОЩАЙ (20.07 №210 п.8), СВИСТУНОВА → УСІКОВА (13.08 №235 п.13), КОБЕЦЬ → КОБЕЦЬ-ШУСТВАЛЬ (16.08 №238 п.22), ЛАПКО → АЗІМОВА (10.09 №263 п.16), ВОЛГА → КОТЛЯРОВА (11.09 №264 п.17), СЕНДЕЦЬКА → САВЧЕНКО (12.10 №295 п.9).

Шесть последних случаев дают расхождения между ОС и АЛФ. В приказе №235 указан девятизначный ИПН 347907668, в обоих листах — 3479407668. В основании приказа №66 указан год 2025 для №45-РС; дата требует проверки. Различия БОНДАР/БОНДАРЬ и СТЕПУРЕНКО/СТЕПУРНЕНКО не подтверждены как смена фамилии. Вывод относится к доступным приказам, а не к полному календарному году.

По просьбе пользователя закрепления сняты на обоих листах; тёмный фон распространён на весь лист через стили всех столбцов. Work/restyle.mjs и Work/darken_sheet.py выполняют эти изменения. Содержимое таблиц сохранено, отсутствие закреплений и сплошной фон проверены в сохранённом XLSX и на превью.
