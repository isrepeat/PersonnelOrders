# Сравнение версий Excel

Скрипт `compare_excel.py` локально сравнивает две книги `.xlsx` и создаёт самостоятельный HTML-отчёт. Старую версию передавать первой, новую — второй. Интернет для сравнения и просмотра отчёта не нужен. Исходные книги не изменяются.

## Запуск

Нужен Python 3.10+ и библиотека `openpyxl`. Если библиотека ещё не установлена:

```powershell
python -m pip install openpyxl
```

Из корня репозитория:

```powershell
python Tools/compare_excel.py "C:\Users\isrepeat\OneDrive\Рабочий стол\РУХ_2026.10.04.xlsx" "C:\Users\isrepeat\OneDrive\Рабочий стол\РУХ_last.xlsx" -o "Results/ExcelComparing/РУХ_last.diff.html"
Start-Process "Results/ExcelComparing/РУХ_last.diff.html"
```

Для следующих сравнений достаточно заменить пути исходников. По умолчанию отчёт записывается в `Results/ExcelComparing/<ExcelFilename>.diff.html`; имя берётся из новой книги без расширения `.xlsx`, например `РУХ_last.diff.html`. Существующий отчёт по указанному пути перезаписывается. Правило `*.diff.html` в `.gitignore` исключает отчёты из Git. Отчёты и `excel-column-widths.json` хранятся в `Results/ExcelComparing/`. Браузер скачивает экспорт JSON в свою папку загрузок; файл нужно сохранить или перенести в `Results/ExcelComparing/`. При блокировке файла сначала сохранить и закрыть книгу в Excel.

## Вид отчёта

- Тёмная коричневая тема, поиск по содержимому и фильтр по типу изменения.
- Закреплённый нижний футер переключает три страницы: «Список», «Отсутствующие» и «Прибывшие» (листы `Список`, `Відсутні`, `Прибулі`). Остальные листы сохраняются в общей сводке и исходном HTML, но не имеют отдельных вкладок.
- Горизонтальная прокрутка общая для всей страницы; у отдельных строк нет своей полосы прокрутки.
- Панель «Ширина столбцов» в футере позволяет менять ширину каждого столбца ползунком или числом от 60 до 600 px. Настройки сохраняются в `localStorage` браузера отдельно по листу и названию столбца; кнопка сброса возвращает 170 px. Сохранение зависит от доступа браузера к локальному хранилищу для `file:`-страниц: при запрете показывается сообщение. Перенос HTML на другой компьютер, другой браузер, приватное окно или очистка данных браузера не гарантируют сохранение настроек.
- Один блок соответствует одной изменённой, добавленной или удалённой строке. Все столбцы с заголовками сохраняются в исходном порядке и расположены горизонтально. Неизменённые и пустые с обеих сторон ячейки показаны нейтральным фоном с `-- // --`. Служебные пустые столбцы без заголовков не выводятся.
- Зелёный фон означает добавленное значение, фиолетовый — заменённое с прежним значением «Было», красный — удалённое.
- Показаны номера строк старой и новой версии, адреса ячеек и названия полей. Все ячейки имеют фиксированный компактный размер 170 × 96 px. Нажатие на ячейку открывает диалог по центру экрана с полным содержимым и прежним значением. Диалог закрывается кнопкой, нажатием вне окна или Esc; ячейку также можно открыть клавишами Enter и пробел.

## Правила сравнения

В раскрывающейся панели ширин футера есть «Экспорт JSON» и «Импорт JSON». Экспорт скачивает `excel-column-widths.json` с настройками всех листов. Импорт восстанавливает весь набор настроек из файла, заменяя текущий, и сохраняет его в браузере. Для колонок без настройки применяется 170 px. Проверяются версия формата, структура и диапазон 60–600 px; при ошибке текущие настройки сохраняются. Формат: `{"version":1,"columnWidths":{"Список":{"ПІБ":200},"Відсутні":{"ПІБ":170},"Прибулі":{"ПІБ":180}}}`.

Сначала сопоставляются полностью одинаковые строки независимо от их позиции, с учётом количества повторов. Перестановка таких строк не считается изменением. Пустые строки и ячейки только с оформлением не учитываются.

Заголовок таблицы определяется по полю `ПІБ`. Оставшиеся записи с одинаковым значением этого поля сопоставляются по наибольшей доле совпадающих заполненных полей: минимум 65%. Для повторяющихся событий одного человека это эвристика; равные по близости кандидаты отмечаются для ручной проверки. При нескольких кандидатах с равной близостью выбирается ближайший по номеру строки. Несопоставленные записи считаются добавленными или удалёнными.

Другой ключ или более строгий порог можно задать явно:

```powershell
python Tools/compare_excel.py old.xlsx new.xlsx --key "Код" --threshold 0.85
```

На листах без ключевого заголовка оставшиеся строки сравниваются по номеру. Это подходит для фиксированных сводок, но перестроенную таблицу лучше сравнивать с явно заданным ключом.

Сравниваются сохранённые значения и тексты формул. Формулы не пересчитываются, их кэшированные результаты, оформление, макросы, комментарии и скрытость строк не сравниваются. Пустая строка и пустая ячейка эквивалентны; числовое и текстовое представления одинакового значения также эквивалентны.

Если заголовки таблицы различаются, скрипт останавливается с ошибкой, чтобы вставленный столбец не вызвал ложные изменения всех ячеек. Автоматическое сопоставление добавленных, удалённых и переименованных столбцов пока не реализовано. Нулевая сводка столбцов относится только к совпадающим заголовкам; вне распознанных таблиц структура столбцов отдельно не анализируется.

## Правило для будущих изменений

При доработке сохранять горизонтальные блоки, текущую тёмную тему и значения «Было». Не подменять неоднозначное сопоставление уверенным результатом. Изменения алгоритма проверять на вставке и удалении строк, перестановках, повторяющихся ключах, пустых значениях и формулах. Проверять баланс количества записей: старые + добавленные − удалённые = новые. Исходные книги не перезаписывать.
